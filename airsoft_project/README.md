# 🎯 Airsoft Equipment Classifier API

API для автоматической классификации страйкбольного снаряжения по текстам объявлений и фотографиям.

## 📋 Описание

Проект реализует машинное обучение для:
- **Классификации по тексту**: определение категории снаряжения из описания объявления
- **Классификации по изображениям**: распознавание оборудования на фото
- **Мультимодального анализа**: комбинирование текста и фото для повышения точности
